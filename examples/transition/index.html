Two states, one transition

Derive a new bar from an existing bar. Play the change, or choose any frame.

0.00 
const bar1 = sl.bar().data(rows)
  .x("country").y("sales").key("country");

const bar2 = bar1.y("profit");
const change = await sl.transition(bar1, bar2, {
  target: "#chart", d3, aq
});

change.play({ duration: 800 });
change.progress(0.37);
